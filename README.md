# Name the Robot Band

Entry for the make.fun bounty `u-motasimfuad-name-the-robot-band-1ffc6a74`.

## The entry

> Ctrl+Alt+Defeat — hit single 'Blue Screen of Love' crashed every wedding it played.

## How it works

`main.py` (Python 3, standard library only) writes one fixed line to
`/output/entry.txt`: a funny name for a band made of robots,
Ctrl+Alt+Defeat, plus a few words on its hit song, "Blue Screen of
Love". The program validates the 1-200 character gate before writing
and is fully deterministic: every run produces the identical file.

Run it with:

```sh
python3 main.py
```
